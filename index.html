Ключевые преимущества

Высокая производительность

Минимальное потребление ресурсов CPU и GPU. Программа стабильно работает даже на встроенных видеокартах начального уровня (например, AMD Radeon R3).

Поддержка устаревших форматов

Нативная поддержка мониторов с соотношением сторон 4:3. Алгоритмы записи исключают искажение пикселей и черные полосы.

Открытый исходный код

Проект полностью прозрачен. Исходный код доступен в репозитории на GitHub под лицензией open-source.

Системные требования

Операционная система Windows 10 / Windows 11 (64-bit)
Процессор (Минимум) Уровня AMD A4-9120 или аналогичный 2-ядерный ЦП
Графика Встроенная графика (AMD Radeon R3 Graphics или выше)
Оперативная память От 4 ГБ
Платформа .NET 8.0 (Устанавливается автоматически)

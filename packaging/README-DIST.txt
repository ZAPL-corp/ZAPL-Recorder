ZAPL Recorder — портативная сборка
===================================

Что внутри
----------
  zapl-recorder(.exe)      сама программа
  bin/ffmpeg               движок захвата и кодирования (уже в комплекте)
  run-windows.bat          запуск на Windows
  run-linux.sh             запуск на Linux
  config.example.json      пример конфигурации (не обязателен)
  README.md                описание проекта
  README-FIRST.txt         этот файл
  docs/QUICKSTART.md       быстрый старт
  THIRD-PARTY.md           лицензии сторонних компонентов
  LICENSE                  лицензия проекта (MIT)

Как запустить
-------------
Windows: двойной клик по run-windows.bat или zapl-recorder.exe.
Linux:   chmod +x run-linux.sh zapl-recorder bin/ffmpeg
         ./run-linux.sh

Папка bin не обязательна: если ffmpeg уже установлен в PATH, программа найдёт его.
Если ffmpeg не найден, интерфейс запустится, но запись и стрим будут недоступны.

Где лежат настройки
-------------------
Windows: %APPDATA%\ZAPL-Recorder\config.json
Linux:   ~/.config/ZAPL-Recorder/config.json

В config.json сохраняются сцены, профили, устройства звука и ключи стрима.
Ключи хранятся в открытом виде — не выкладывайте файл в публичные места.

Быстрая проверка
-----------------
1. Запустите программу.
2. Справа вверху должен быть зелёный статус ffmpeg (например «NVENC · DXGI»).
3. Нажмите «Начать запись» — файл появится в папке из «Настройки → Общие».

Ограничения
-----------
* Браузерный источник захватывает область экрана: окно браузера должно быть
  открытым, находиться в заданном регионе и не быть перекрытым.
* Стрим идёт по RTMP. Одновременная трансляция на две площадки не поддерживается.
* Linux: X11/XWayland. Для источника «Окно» нужен xdotool.
* Превью останавливается на время записи, чтобы не тратить CPU.

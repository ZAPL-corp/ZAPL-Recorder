# GitHub Page
> [!NOTE]
> Весь исходный код страницы находится в ветке `gh_page`

## Coding
Страница сама по себе нуждается в обязательном редизайне, именно по этому мы даём вам, пользователям, возможность проявить свои умения
в редактировании HTML вёрстки, мы ждём от вас Pull Request с страницей формата .html (желательно одним файлом но можно с роутами)

Просто создайте форк репозитория и загрузить .html файл в корень, после чего создайте PR и ожидайте его одобрения!

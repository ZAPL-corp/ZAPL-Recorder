# Быстрый старт

## 1. Распакуйте папку

В архиве лежит папка `ZAPL-Recorder` целиком. Не вынимайте из неё
`zapl-recorder` и `bin/ffmpeg` по отдельности: программа ищет ffmpeg рядом с
собой.

## 2. Запустите

**Windows.** Двойной клик по `run-windows.bat` (или `zapl-recorder.exe`).

**Linux.**

```bash
chmod +x run-linux.sh zapl-recorder bin/ffmpeg
./run-linux.sh
```

Если приложение не стартует на Linux, проверьте, что установлены библиотеки
X11/OpenGL (обычно уже есть в рабочем столе):

```bash
sudo apt install libxkbcommon0 libgl1 libx11-6
```

## 3. Проверьте ffmpeg

В правом верхнем углу — статус вида `ffmpeg · NVENC · DXGI`. Если написано
«ffmpeg не найден»:

- Windows: положите `ffmpeg.exe` в папку `bin` рядом с программой;
- Linux: положите `ffmpeg` в `bin/` и сделайте `chmod +x bin/ffmpeg`;
- либо установите ffmpeg в `PATH` и нажмите на статус, чтобы проверить снова.

## 4. Первая запись

1. В левой панели сцена «Рабочий стол» и источник «Захват экрана».
2. Внизу — «Начать запись».
3. Слева внизу превью появится `REC` и таймер.
4. «Остановить запись». Файл — в `Видео/ZAPL Recorder` (Windows) или
   `~/Видео/ZAPL Recorder` (Linux).

## 5. Стрим

1. «Настройки → Стрим».
2. Нажмите `+ Twitch`, `+ YouTube` или `+ Kick`.
3. Вставьте ключ потока из панели площадки.
4. Нажмите «Выбрать» у нужной площадки, закройте настройки.
5. «Начать стрим». Внизу слева — `LIVE`, FPS, битрейт и потери.

## 6. Добавить окно или браузер

- «+ Источник → Окно»: введите часть заголовка окна.
- «+ Источник → Браузер»: введите URL и нажмите «Открыть окно браузера».
  Окно встанет в регион из карточки источника; не перекрывайте его.

## 7. Настройка под слабый ПК

- Режим: «Запись работы» или «Стрим работы».
- Видео: 1280×720, 30 fps.
- Вывод: x264, preset `ultrafast`.
- Превью: выключить на время записи (оно и так отключается автоматически).
- Формат: MKV.

## Частые проблемы

**Запись стартует и сразу падает.** Откройте «Инструменты → Журнал и команда
ffmpeg»: там последняя команда и лог ffmpeg. Чаще всего это неверное
устройство звука или занятый монитор.

**Нет звука.** «Настройки → Аудио», нажмите «Найти устройства» и выберите
устройство. На Windows системный звук требует `virtual-audio-capturer`; на
Linux — monitor-источник из `pactl list short sources`.

**Стрим обрывается.** Снизьте битрейт в «Настройки → Вывод» (например,
2500–3500 кбит/с для 900p30).

**Linux: окно не находится.** Установите `xdotool`:

```bash
sudo apt install xdotool
```

**Wayland.** Захват работает через XWayland; если окно не видно, запустите
сессию X11.
